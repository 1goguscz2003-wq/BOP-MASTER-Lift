# BOP MASTER Lift

Отдельная мобильная система вызова строительного лифта для этажей -1, 0, 1, 2, 3, 4, 5.

## v3
- постоянный QR для каждого этажа;
- статус лифтёра «на месте / нет на месте»;
- умная очередь по текущему этажу лифта;
- расчёт маршрута: примерно 5 секунд на один этаж;
- автоматический выбор следующего ближайшего вызова;
- отметка BOSS у удалённых вызовов;
- кабинет лифтёра;
- кабинет BOSS;
- неограниченное количество BOSS-аккаунтов;
- админ может создавать, удалять и перевыпускать BOSS-ключи;
- админ и BOSS могут перевыпустить ключ лифтёра;
- старый ключ лифтёра сразу перестаёт работать;
- BOSS может удалённо вызвать лифт на любой этаж;
- админ-панель, статистика, история и QR;
- ручное обновление сразу всех 7 QR;
- автоматическая очистка старых ожидающих вызовов;
- интерфейс рассчитан в том числе на экраны от 240 px шириной.

Backend: отдельный Supabase проект `BOP MASTER Lift`.
